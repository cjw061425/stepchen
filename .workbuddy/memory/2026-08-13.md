## 图标不生效问题排查与修复(第四次)

- **根因**: main.css URL 无版本号,浏览器缓存旧 CSS(旧 CSS 只有 github-link/twitter-link 规则,新 HTML 的 email-link/douban-link 匹配不到样式 → 图标不显示;weibo 没变所以正常)
- **修复**: `themes/prince/_config.yml` 加 `asset_version: 2`;`head.jade` 三个 CSS 链接加 `?v=#{theme.asset_version}`。以后改 CSS/JS 记得 bump asset_version
- **Cloudflare 邮箱混淆**: stepchen.com 走 Cloudflare,mailto: 被自动改写为 /cdn-cgi/l/email-protection#...(需 Cloudflare JS 解码点击)。若要直接显示真实 mailto,需在 Cloudflare 面板关闭 Email Address Obfuscation
- **排查要点**: 线上文件与分支内容正确不代表用户看到新内容,缓存是常见元凶;`curl 带随机参数` 可绕过 CDN 缓存验证;GitHub Pages HTML 响应 `cf-cache-status: DYNAMIC`
